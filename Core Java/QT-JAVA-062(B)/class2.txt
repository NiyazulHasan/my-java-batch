Flavours in java
================
We have three flavours in java.


					JAVA
	|--------------------------------|-----------------------------|

				> N-tier App 
		


> Standalone App
----------------
A normal java program which contains main method is called standalone application.
ex:
	class Test
	{	
		public static void main(String[] args)
		{	
			-
			- //some logic		
			-
		}
	}

> Desktop App
-------------
It is a software application specially designed to perform perticular task.
ex:
	Control Panel 
	Recycle Bin 
	VLC Media player 
	and etc.

> Two-tier App 
--------------
Having more then one tier is called two-tier application.

> Distributed App
-----------------
Diagram: class2.3

In client/server application, if multiple requests go to main server then main server will distribute those requests to parallel servers to reduce the burdun of main server such type of application is called distributed application.

ex:
	JIO Hotstar



> Enterprise App
----------------
An application which deals with large business complex logic with the help of middleware services is called enterprise application.

Here middleware services means authentication, autherization, malware production, security and etc.

ex:
	Zoom Meeting 
	Facebook 
	Online Shopping Website 


> ERP App 
----------
ERP stands for Enterprise Resource Planning.

It is a integrated software that organizations use to manage and automate core business processes. It acts as a central hub, connecting departments like finance, HR, supply chain, and manufacturing so they share a single source of data.

Diagram: class2.4


> N-tier App
-------------
Having more then one two tiers is called N-tier application.
